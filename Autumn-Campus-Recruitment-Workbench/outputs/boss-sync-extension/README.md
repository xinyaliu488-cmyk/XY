# JobLens BOSS Sync

这个 Chrome 扩展在已登录的 BOSS 直聘搜索页面中读取公开职位卡片，并同步到本地 JobLens 服务。它不会读取密码、导出 Cookie 或绕过安全验证。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`outputs/boss-sync-extension`。
5. 保持本地 JobLens 服务运行，并确保 BOSS 直聘已登录。

## 使用

- 点击扩展图标，再点击“立即同步”。
- 扩展每 30 分钟自动同步一次。
- 如果 BOSS 出现安全验证，手动验证后页面会自动继续同步。
- 本地服务地址固定为 `http://127.0.0.1:4173`。

扩展只读取当前关键词“前端 React”、城市“上海”的搜索结果。后续可以把关键词和城市改成可配置项。
